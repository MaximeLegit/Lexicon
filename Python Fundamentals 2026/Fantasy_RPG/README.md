This file containt simple instructions on the intent of the program.
The program is an RPG, input based game. One is required to read programs output in the terminal and provide a corresponding input.
Question -> Answer relaptionship.

When begin_rpg() function is run within the main function, one has to either:
Make a character, once more, by following the output/input relationship OR
Use a generated character that the program offers.

Once this step is complete, the program has a main scenarion, which is referred to Begin Story. It has 3 steps.
ALternatively, one has the option of infinite fighthing, however, it is loop based. Values for health can be hardcoded, for certain scenarios.

In the story version, depending on your input, certain actions can be done, of ocurse, they are input based with respect to 
what is shown in the terminal. ALl of those steps are designed to have a playable game so that you reach the final destination, and perhaps,
one day, defeat the greatest King of Heroes. 

Points to mention.
1.  In story part 1, when one is in the "welcome to the game loop", in order to rpoceed with the story, keywords such as:
    church, explore, exploration, cathedral are key to proceed further. Similarly, if one wish to talk to the keep a second time,
    if one wishes to experience a 2nd set of dialogue, keywords of interest are: liquid, beverage or drink in any sentence or as standalone. 

2.  Input of nature Y/N can of course be set as 'Y', 'N', 'y' or 'n' respectively. The program is meant to cater for that.

3.  Dialogue with smithy. The smithy responds to any sentence, and the keywor to proceed there is either journey or battle to get better gear.
    Answering anything else than that, or any sentence without those words would result in one exiting the conversation and going back to 
    continuation of Chapter 2.

4.  I made that so that unless you hit perfect conditions, you do not even stand a chance against the final opponent, however, that does not
    mean you should not try right? In order to have achance to beat the final opponent, you must use every trick in the book, every item you
    can possibly pick up, hence the game is based on the loop to attempt to explore all options, and try again.
